# 棋友 / KIYU — 製品の原点と到達目標

最終更新: 2026-11-15 / 企画オーナー: ユーザー / 状態: ユーザーの会話から整理した設計の正本

## 一文で表す

**「将棋を全く知らない日から有段者になった後まで、同じライバルと指し、話し、互いの成長を感じられるアプリ」。**

単なるCPU対戦、AI棋譜解析、講義動画の寄せ集めではない。「一緒に盤を挟む存在」と「本当に強くなれる教育課程」を統合する。

## ユーザーが確認した要求（必須の到達目標）

### 1. 生涯のライバル

- 人間としてあり得る強さ・ミス・棋風を備えた対戦AI。常時最善手の無敵エンジンでも、無秩序な悪手を打つだけのAIでもない。
- 初心者から有段者まで相手になる幅広い棋力。ユーザーの成長に合わせた互角の戦いも、挑戦的な設定も提供する。
- 居飛車・振り飛車、さまざまな戦型・囲い・局面に対応する**オールラウンダー**。一つの決まった定跡だけを反復しない。
- 棋力とプレイスタイルを別々に制御し、後に長期的なライバルの人格・成長史も表現できる構成にする。

### 2. 人間味のある会話・関係

- 対局前後、感想戦、雑談を自然な日本語で交わす。勝った時は勝った、負けた時は負けたと受け止める。
- 互いの対局や学習の履歴を覚え、単発セッションをまたぐ「共に成長する感覚」を作る。
- 局面評価や助言は実際の盤面・棋譜に基づき、AIが誤った勝敗や根拠のない読み筋を語らない。

### 3. 一貫した教材モード

- 将棋を初めて指す人でも始められ、実力に応じて**有段者が使い続けられる**内容に到達する。
- 駒の動き・将棋のルール、囲い、戦法・戦型講義と練習、序盤の組み立て、中盤の攻防、終盤の立ち回り、詰将棋、実戦研究を体系的に扱う。
- 読んで終わりにせず、盤上で解く→対局で試す→感想戦→時間を置いて復習、をつなぐ。
- 最適化は「いたずらに難しくすること」ではなく、弱点を見つけて上達のために必要な学習を与えること。

### 4. ビジュアル・使用環境

- **大人びた、スタイリッシュで、どこか和風な雰囲気**。落ち着いた色、余白、盤や駒の質感。過度な幼児向け・ソーシャルゲーム的装飾は避ける。
- iPhone等のスマートフォンを第一級の利用環境として扱い、盤・駒の視認性、成り、持ち駒、操作性を重視する。

## 現在の試作の位置付け

試作第1号で基本UI・合法手の一部・簡易対局・基礎教材・履歴・限定会話を体験済み。試用の価値はあったが、上記のビジョンを満たしたわけではない。**「Lv.4ですらかなり弱い」**という実際の感想があり、棋力は最優先級の課題。

## 提案段階の実装原則（未承認の詳細を確定扱いしない）

1. 将棋エンジン（正しい局面・手・形勢）と、対戦相手の棋風／強さ制御を分離。
2. 会話モデル（人格・話し方）と、事実の検索・棋譜解析を分離。
3. 教材の説明・問題・解答の正確性は機械検証＋人間のレビューを併用。
4. 履歴・習熟度・好みをユーザーがエクスポート／削除できるようにする。
5. プロトタイプから本格版への移行で対局記録を失わないようにする。

## 成功の測り方（後に数値・評価基準を決める）

| 軸 | 必要な検証 |
| --- | --- |
| 棋力の幅 | 入門〜有段の異なる実力帯に対して指定した対局強度で指せるか |
| 人間味 | 棋風・局面に沿った実在し得るミスをするか、対戦が不自然でないか |
| オールラウンド性 | 複数の居飛車・振り飛車戦型に対応し、序盤が偏りすぎないか |
| 教材効果 | 初見テスト、練習、実戦、遅延確認で習熟が向上するか |
| 会話の一貫性 | 前の対局や発話を正しく参照し、推測を事実と混同しないか |
| 信頼性 | 合法手・棋譜保存・同期・復旧・iPhone描画が安定するか |
